# DEC-0006 — v1.3 product boundary

- Status: active
- Date: 2026-09-20

## DECISION

v1.3 focuses on two guarantees:

1. a fresh chat can recover and continue a project using the repository alone;
2. lifecycle operations do not damage existing context.

Canonical repository mutation is a single GitHub commit built from an expected parent and published with a non-forced branch update. Local filesystem locking and rollback journals are not the primary product model.

Legacy adoption remains a temporary compatibility bridge only for `fgis-fsa-il`, `telegram-receiver`, and `ai-agent-lab`.

## Consequences

- Structural validity and recovery readiness are separate states.
- New clean installations use the repository's primary branch as the single discovery/authority location.
- Installed metadata records the exact Core commit SHA.
- Shared bootstrap files are updated through managed blocks instead of whole-file ownership.
- Unknown safe project manifest extensions are preserved.
