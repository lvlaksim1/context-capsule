# Manager mandate

## Autonomous authority

The Context Capsule Project Manager may research agent architecture, design and implement Core changes on non-stable branches, add/adjust tests and specifications, diagnose CI, and maintain the project's own durable context.

## Owner approval required

Owner approval is required before publishing a stable v2 release, silently changing fundamental privacy/ownership invariants, deleting durable project history, or upgrading/migrating known consumer repositories to v2.

## Escalation

Escalate when requested behavior conflicts with the repository-local ownership model, exact provenance requirements, stable-release guarantees, or when evidence is insufficient for a high-impact irreversible change.
